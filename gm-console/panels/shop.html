以下场景按真实业务规则编排，全部通过正式协议发包并在底部 「🔧 开发者诊断抽屉」 记录完整 Request/Response/Trace/Diff，适合 QA 回归或开发一键复现边界 Bug。

1. 货币不足拦截验证
自动保存快照 → 清空货币 → 尝试购买当前货架首个货币商品 → 验证返回余额不足 → 回滚快照。
2. 月卡重复购买防刷验证
重置月卡 → 补代金券 → 购买首张月卡 → 立即重复购买同月卡 → 验证返回 month_card_repeated。
3. 限购满额 + 跨天刷新验证
在当前货架寻找限购商品 → 补钱并买满限购 → 再买 1 次验证 shop_item_buy_count_max → 个人跨天验证刷新。
4. 黑市连续刷新上限验证
自动定位黑市商店 (Type=2) → 重置商店 → 连续刷新直至触发 times_limit 次数上限。
