## 3. 本次迁移处理

主文档保留已核实的模块边界、邮箱调度、RPC、混合持久化和配置链路，区分当前实现、开发约束与优化候选；旧文中不准确的包头、线程安全保证、配置命名空间、公会加载过程和持久化描述，以主文档的源码说明为准。

旧文中有价值的优化方向，经核实后补为三个可验证的评估方案：

- [01 §13.1 Worker 与 JDBC 执行方式](01_系统架构设计全景文档.md#131-worker-与-jdbc-执行方式的对比评估)：明确排队、连接池与 SQL 的测量边界，以及受限执行方案的对比条件。
- [01 §13.2 JSON 快照增量优化](01_系统架构设计全景文档.md#132-json-快照增量优化与格式迁移)：明确完整聚合写入、保存期间新变化、失败重试和格式兼容要求。
- [01 §13.3 trace 上下文传播](01_系统架构设计全景文档.md#133-trace-上下文跨邮箱传播)：明确请求、邮箱、DAO/RPC 和异步完成之间的传播、清理与验证范围。

上述方案尚未实施；性能收益和可靠性结论由对应任务的实际验证决定。
